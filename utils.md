# Ordre des exercices AI.GO

Ordre logique déduit des dépendances indiquées dans les sujets : chaque exercice
réutilise le code et les notions du précédent.

## 1. Construire le robot (HTML/CSS)

1. `the-skeleton`
2. `call-it`
3. `select-then-style`
4. `embedded-organs`
5. `class-it`
6. `first-move`

## 2. Bases JavaScript

7. `glance-on-power`
8. `star-forge`
9. `declare-everything`
10. `play-with-variables`
11. `the-smooth-operator`
12. `first-function`
13. `objects-around`
14. `transform-objects`
15. `good-recipe`
16. `only-if`
17. `listed`
18. `i-win-arguments`

`i-win-arguments` est annoncé comme la dernière mission « power ».

## 3. Donner vie / interagir avec le robot

19. `first-wink`
20. `first-hello`
21. `colorful-arms`
22. `colorful-legs`

## 4. Projet final (raid en équipe)

23. `robots-harmony`

## Remarques

- `first-move` se fait avant les bases JavaScript (le sujet précise « you haven't
  learned much about JavaScript yet »).
- `first-wink` se fait après les bases JavaScript (« using the power you gained,
  JavaScript basics »).
- L'ordre exact de quelques exercices JS (11 à 17) peut varier selon la
  plateforme, mais celui-ci respecte les prérequis explicites des README.
